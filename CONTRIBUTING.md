# Contributing

Run `npm ci --ignore-scripts`, `npm test`, and `npm run build` before a pull request. Use original synthetic fixtures. Keep permissions minimal, executable code local, and packaging allowlisted.

Preserve source text, order, links, figures, captions, citations, authors, table spans, and original account actions. Prefer reversible presentation changes and skip unknown structures. Do not add crawling, analytics, remote code, medical rewriting, or bundled book content.

Use English for comments, documentation, and extension strings. Never commit tokens, cookies, patient information, member-site captures, or copyrighted excerpts. Report the version, route, viewport, and a synthetic reproduction where possible.
